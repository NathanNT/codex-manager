    Comprendre les données affichées

    Une fenêtre disparaît environ une minute après son dernier signal de présence. Le pourcentage disponible désigne le quota de la fenêtre de temps indiqué, et non un solde monétaire.

    Quand plusieurs fenêtres ouvrent le même projet, la conversation est signalée comme ambiguë sous le compte. Le goal vient de la conversation enregistrée ; l'activité du chat vient des hooks, du dernier tour connu ou d'une estimation locale identifiée. « Tâche arrêtée » signifie que le dernier travail de l’agent a été interrompu. Un goal ouvert peut attendre le prochain message sans agent au travail. « — » signifie que le relevé n'a pas été publié.

    Le type d'abonnement est fourni par Codex. Sa date de renouvellement ou de fin n'est pas fournie par l'App Server ; elle se consulte dans les paramètres de facturation ChatGPT de chaque compte.
